Privacy Policy

Last updated: August 2026

This project ("thegoodscroll bot") is a personal, automated script that periodically republishes public content (images) to social media accounts owned by the developer (Instagram, Facebook, TikTok), citing the original source.

What data we collect

This application does not collect, store, or process personal data belonging to other users. The only data retained is a list of content IDs that have already been republished, used solely to avoid posting duplicates — stored locally, in the project's code repository, with no personal information attached.

What access we request

This application uses the official APIs of each platform (Instagram Graph API, Facebook Graph API, TikTok Content Posting API) exclusively to publish content to the developer's own account. We do not access or read data belonging to other users of these platforms.
